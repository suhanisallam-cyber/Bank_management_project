#  Bank Management System

A SQL-based Bank Management System created using MySQL.

## Technologies Used
- MySQL
- SQL

## Database Tables
- Customers_data
- Accounts
- Transactions
- Loans
- Branches

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- LEFT JOIN
- Aggregate Functions
- Subqueries
- CASE
- Foreign Keys

## Project Objectives
- Manage customer information
- Analyze bank accounts
- Analyze deposits and withdrawals
- Analyze loans
- Practice SQL queries and database relationships
